# 冲刺计划 · 使用与更新说明

一个纯静态的网页应用（PWA）：**装到手机和电脑上像 App 一样用，断网也能打开，数据只存在你自己的设备里**，不经过任何服务器。

---

## 一、文件夹里都是什么

```
学习计划/
├── index.html            页面骨架（一般不用改）
├── manifest.webmanifest  App 名称 / 图标 / 启动方式
├── sw.js                 离线缓存（保证断网能开、改了能更新）
├── assets/
│   ├── config.js         ★ 改内容就改这个：考试日期、科目、每日模板、阶段计划、作息、提醒
│   ├── style.css         样式（颜色、字号、间距）
│   └── app.js            功能逻辑（增删任务、统计、番茄钟）
└── icons/                应用图标
```

## 二、第一次安装

### 方案 A：部署到网上（推荐 —— 手机、电脑共用一个网址，一次配置长期用）

**用 GitHub Pages（免费、稳定）：**

1. 打开 [github.com](https://github.com) 注册 / 登录
2. 右上角 **+ → New repository**，名字填 `study-plan`，选 **Public**，点 **Create repository**
3. 点 **uploading an existing file**，把这个文件夹里的**所有内容**拖进去
   （注意：`assets` 和 `icons` 两个子文件夹要一起拖，网页版支持拖文件夹）
4. 点 **Commit changes**
5. 进 **Settings → Pages** → Source 选 **Deploy from a branch** → Branch 选 **main** + **/(root)** → **Save**
6. 等 1 分钟，打开 `https://你的用户名.github.io/study-plan/`

**装成 App：**

- **电脑**：用 Edge 或 Chrome 打开上面的网址 → 地址栏右侧出现「安装」图标（或菜单 → 应用 → 安装此站点为应用）→ 桌面/任务栏就有图标了，打开是独立窗口，没有地址栏
- **安卓**：Chrome 打开 → 右上角 ⋮ → **添加到主屏幕 / 安装应用**
- **iPhone**：**必须用 Safari** 打开 → 底部分享按钮 → **添加到主屏幕**

> 也可以换成 Cloudflare Pages、Netlify、Vercel，操作类似：把文件夹拖进去，得到网址即可。

### 方案 B：只在这台电脑上用

双击 `index.html`，用 Chrome / Edge 打开。功能完全一样，但不能"安装成应用"，而且地址栏会一直在。

> ⚠️ 方案 A 和方案 B 的**数据不互通**（浏览器把它们当成两个不同来源）。选定一种就一直用那种。

## 三、以后怎么改

| 想改什么 | 改哪个文件 | 例子 |
| --- | --- | --- |
| 考试日期、考试名称 | `assets/config.js` 的 `exams` | 官方公布日期后改 `date` |
| 科目（增删、改颜色） | `assets/config.js` 的 `subjects` | 加一个 `{id:'x', name:'政治2', color:'#e11d48'}` |
| 每日模板 | `assets/config.js` 的 `template` | 加一条 `{title:'作文默写', cat:'cet', mins:20}` |
| 阶段计划内容 | `assets/config.js` 的 `phases` | 改文案、加阶段 |
| 作息表 / 每日提醒 | `assets/config.js` 的 `schedule` / `tips` | — |
| 颜色、字号、间距 | `assets/style.css` | 顶部 `:root` 里的变量 |
| 功能（加按钮、加统计） | `assets/app.js` | 找 `/* ========== xxx ========== */` 分区块 |

**改完怎么生效：**

- 本地：保存后刷新页面（Ctrl+F5 强制刷新最稳）
- 线上：在 GitHub 仓库里 **上传同名文件覆盖**（或 `git push`）→ 手机/电脑下次打开会自动拿到新版，App 会弹「发现新版本，正在更新…」并自动刷新

## 四、数据在哪 / 怎么同步

- 数据存在浏览器的 `localStorage`，键名 `study-planner-v1`
- **不上传服务器**；想两边一致，用下面的「云同步」

### 云同步（GitHub Gist，已内置）

思路：拿你的 GitHub 账号当"账户"，数据存在你自己账号下的一个**私有 Gist** 里。两台设备填同一个令牌，就会自动合并。

1. 打开 App → 设置 → **云同步** → 点「去创建令牌」（链接已自动勾好 `gist` 权限）
2. 页面拉到底点 **Generate token**，复制 `ghp_` 开头那串（只显示一次）
3. 粘到输入框 → **连接**。第一次会创建云端存档并上传
4. **另一台设备做同样的操作，粘同一个令牌** —— 它会自动找到你的存档，把数据拉下来

之后：每次改完约 4 秒自动上传；打开 App、切回前台会自动拉一次；设置里也有「立即同步」。

**冲突规则**：按"天"比较，同一天以最后修改的为准；不同天的修改互不影响，会合并。
**令牌安全**：令牌只存在本机浏览器（`localStorage`），不会写进网页、不会上传到 Gist。
**断开**：设置 → 云同步 → 断开，只删本机令牌，云端存档保留。

> 想彻底删掉云端数据：打开「查看云端存档」→ Gist 页面 → Delete gist。

### 手动备份

设置 → 导出备份（`.json`）。换设备、换浏览器前建议导一次。

## 五、常见问题

**Q：改了代码，打开还是旧的？**
等 2 秒会自动刷新；没反应就 Ctrl+F5，或在「设置 → 版本与更新 → 检查更新」。

**Q：手机上打开是白屏？**
大概率是 `assets` 或 `icons` 没上传完整。检查仓库里 `assets/config.js` 能不能直接打开。

**Q：手机上图标是空白方块？**
上传时漏了 `icons` 文件夹，或路径大小写不一致（服务器区分大小写，Windows 不区分）。

**Q：能加第三个考试吗？**
能，在 `config.js` 的 `exams` 里加一条（`id` 不要重复），倒计时卡片会自动多一张。

**Q：能不能做成真正的 APK / exe？**
可以（Capacitor / Tauri），但每改一次就要重新打包，你现在这种"改配置 + 刷新"的方式更适合持续调整。
